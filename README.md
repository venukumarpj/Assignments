# Assignments Website

A responsive, static front-end website for the Assignments academic and digital support brand.

## Included
- `index.html` — page content and structure
- `style.css` — responsive styling
- `script.js` — mobile navigation and current footer year
- `images/logo.png` — supplied Assignments logo

## Run locally
Open `index.html` in a web browser. An internet connection is needed to load the Google Font; the site otherwise works as a static website.

## Publish with GitHub Pages
1. Sign in to GitHub and create a new **public** repository, for example `assignments-website`.
2. Extract this ZIP file on your computer.
3. Open the new repository and choose **Add file → Upload files**.
4. Upload the contents of the extracted `assignments-website` folder. Make sure `index.html`, `style.css`, `script.js`, and the `images` folder are at the repository root (do not upload an extra nested folder).
5. Enter a commit message such as `Add website frontend`, then click **Commit changes**.
6. In the repository, open **Settings → Pages**.
7. Under **Build and deployment**, choose **Deploy from a branch**.
8. Select branch **main** and folder **/(root)**, then click **Save**.
9. Wait for GitHub Pages to publish. The site URL will appear in **Settings → Pages** and usually follows `https://YOUR-USERNAME.github.io/assignments-website/`.

## Updating the website
Edit the files, upload the changed files to the same repository, and commit the changes. GitHub Pages will publish the update automatically.

## Customization notes
- The location is set to **Chennai, Tamil Nadu, India**.
- No personal phone number, email address, or Instagram username is included.
- The contact section invites visitors to use the social platform where they found the business, without exposing account details.
- This is a front-end-only static site. It does not include a database, login system, payment processing, or an online enquiry backend.
